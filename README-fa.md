# افزونه PressPilot

این افزونه یک **REST API امن** روی سایت وردپرسی شما باز می‌کند تا یک دستیار هوش مصنوعی (مثل Claude)
بتواند صفحات شما را با **المنتور** و **المنتور پرو** بخواند، بسازد و ویرایش کند — بدون نیاز به هیچ دسترسی
FTP یا SSH یا اجرای PHP روی هاست. همه‌چیز فقط از طریق همین API انجام می‌شود.

> نکته: تست کامل این افزونه روی WordPress + Elementor انجام شده و ساخت صفحه از صفر، ویرایش،
> آپلود عکس و رندر نهایی روی سایت تأیید شده است.

---

## ۱) نصب (خیلی ساده — نیازی به دانش فنی ندارید)

۱. کل پوشه‌ی `elementor-ai-assistant` را به صورت یک فایل **zip** در بیاورید (یا از فایل زیپ آماده استفاده کنید).
۲. وارد پیشخوان وردپرس شوید: **پیشخوان → افزونه‌ها → افزودن → بارگذاری افزونه**.
۳. فایل zip را انتخاب و روی **اکنون نصب کن** بزنید، بعد **فعال کردن**.
۴. مطمئن شوید **Elementor** (و در صورت داشتن، **Elementor Pro**) هم روی سایت فعال است.

## ۲) گرفتن کلید اتصال

بعد از فعال‌سازی به این آدرس بروید:

**پیشخوان → تنظیمات → AI Assistant**

در این صفحه دو مقدار می‌بینید:

- **REST Base URL** — مثلاً `https://your-site.com/wp-json/presspilot/v1`
- **API Key** — یک کلید محرمانه‌ی طولانی

این دو مقدار را برای دستیار هوش مصنوعی بفرستید. همین! از این به بعد دستیار می‌تواند به سایت وصل شود.

> 🔒 **کلید را محرمانه نگه دارید.** هر کسی این کلید را داشته باشد می‌تواند صفحات سایت شما را ویرایش کند.
> اگر نگران شدید، در همان صفحه دکمه‌ی **Regenerate API Key** کلید جدید می‌سازد و کلید قبلی باطل می‌شود.

## ۳) تست اتصال

در همان صفحه‌ی تنظیمات یک دستور آماده هست. اگر ترمینال دارید، این را اجرا کنید (به‌جای مقادیر، مال خودتان را بگذارید):

```bash
curl "https://your-site.com/wp-json/presspilot/v1/ping" -H "X-PressPilot-Key: کلید-شما"
```

اگر جواب `{"ok":true,...}` گرفتید، یعنی همه‌چیز درست کار می‌کند. ✅

---

## نکات فنی مهم

- اگر آدرس `/wp-json/...` روی هاست شما کار نکرد (خطای ۴۰۴)، معمولاً کافی است در
  **تنظیمات → پیوندهای یکتا (Permalinks)** یک بار روی **ذخیره** بزنید تا قوانین بازنویسی به‌روز شوند.
  در غیر این صورت می‌توان از فرم جایگزین `https://your-site.com/?rest_route=/presspilot/v1/ping` استفاده کرد.
- افزونه هیچ صفحه‌ای را بدون دستور شما تغییر نمی‌دهد؛ فقط ابزار اتصال است.
- برای امنیت بیشتر توصیه می‌شود سایت روی **HTTPS** باشد تا کلید در مسیر لو نرود.

جزئیات کامل همه‌ی مسیرهای API در فایل [`docs/API.md`](docs/API.md) هست.
